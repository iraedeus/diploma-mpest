# Интерактивный веб-дашборд анализа требований и литературы

Скрипт [`generate_dashboard.py`](generate_dashboard.py) предназначен для автоматизированного формирования автономного интерактивного аналитического дашборда [`articles/dashboard.html`](../dashboard.html) на основе эмпирической базы диссертационного исследования (каталог [`articles/raw/`](../raw/)).

---

## 1. Входные данные

Скрипт считывает и реляционно связывает нормализованные CSV-таблицы:
* **Общие реестры (`articles/raw/`)**:
  * `articles/raw/requirements.csv` — таксономия функциональных и архитектурных требований;
  * `articles/raw/articles.csv` — библиографический каталог рецензируемых публикаций;
* **Данные первого дашборда (`articles/raw/reqs/`)**:
  * `articles/raw/reqs/tools.csv` — каталог 27 библиотек моделирования одномерных непрерывных смесей (Python, R, Julia, C++);
  * `articles/raw/reqs/evaluations.csv` — матрица оценок инструментов по требованиям со ссылками на исходный код и доказательными заметками;
  * `articles/raw/reqs/requirement_articles.csv` — семантическая связующая таблица требований со статьями.

Скрипт не требует внешних зависимостей и работает на стандартной библиотеке **Python 3.8+**.

---

## 2. Сборка и запуск

Собрать дашборд:
```bash
python3 articles/scripts/generate_dashboard.py
```

Открыть в браузере:
```bash
xdg-open articles/dashboard.html
```

Параметры запуска:
* `--data-dir <PATH>`, `-d <PATH>` — путь к каталогу с исходными CSV (по умолчанию `articles/raw/`);
* `--output <PATH>`, `-o <PATH>` — путь к результирующему HTML-файлу (по умолчанию `articles/dashboard.html`).

## 3. Интерактивные возможности дашборда

### 3.1. Сводная матрица со светофорной палитрой
* 🟢 **Есть (`yes`)** — возможность полностью реализована в публичном API;
* 🟡 **Частично (`partial`)** — реализована для ограниченного подмножества случаев (например, только 1D или без аналитического M-шага);
* 🔴 **Нет (`no`)** — возможность отсутствует.
* **Закрепленные колонки**: при горизонтальном скролле код, название требования и целевая библиотека `pysatl-mpest` всегда зафиксированы слева.

### 3.2. Инспектор доказательной базы (Evidence Inspector)
* При клике на любой статус открывается модальное окно с детальным описанием (`evidence_note`) и прямой ссылкой на файл / строку кода в GitHub-репозитории пакета (`evidence_link`).

### 3.3. Навигатор литературы и наукометрии (кнопка `📚 N`)
Клик по числу статей в строке требования открывает боковую панель:
* **Фильтр по цитированиям**: пороги $\ge 20$, $\ge 50$, $\ge 100$, $\ge 500$, $\ge 1\,000$ (классика);
* **Фильтр по ролям**:
  * `foundation` — фундаментальный теоретический базис;
  * `method` — конкретные алгоритмические методы;
  * `benchmark` — эталонные тестовые наборы и сравнения;
* **Сортировка**: по числу цитирований (убыв.), по году (новые / старые);
* **Ограничение (лимит)**: Топ 5, Топ 10, Топ 25, Все статьи;
* **Экспорт**: копирование отобранного списка в Markdown или BibTeX в 1 клик;
* **DOI-ссылки**: прямой переход к публикации в открытых репозиториях.

### 3.4. Аналитические пресеты
* **🎯 Киллер-фичи `pysatl-mpest`**: требования, где у `pysatl-mpest` статус «Есть», а у большинства конкурентов «Нет/Частично» (основа для раздела о научной новизне);
* **⚠️ Бэклог `pysatl-mpest`**: критические требования (`must` / `should`), которые еще не закрыты;
* **🔥 Только Must-have требования**: ядро функциональности для релиза библиотеки;
* **📚 Высокоцитируемые темы**: требования, подкрепленные публикациями с $\ge 1\,000$ цитирований.

### 3.5. Выбор инструментов и экосистем
* Быстрые табы: **Все (25)**, **Python (8)**, **R (13)**, **Julia / C++ (4)**;
* Модальное окно **«⚙️ Выбрать пакеты»**: мультивыбор чекбоксами для прямого сопоставления 2–3 библиотек (например, `pysatl-mpest` vs `scikit-learn` vs `pomegranate`).

### 3.6. Экспорт для дипломной работы (ВКР)
* Кнопка **«📋 Скопировать Markdown»** — мгновенно копирует текущий отфильтрованный срез таблицы с бейджами 🟢 🟡 🔴;
* Кнопка **«📊 Экспорт CSV»** — скачивает текущий срез в формате CSV.
