\section{Постановка задачи}
\label{sec:task}

Целью работы является развитие библиотеки pysatl-mpest для оценки параметров и выбора структуры конечных смесей одномерных непрерывных распределений, а также публикация её релиза.

Для достижения этой цели необходимо решить следующие задачи:

\begin{enumerate}
    \item\label{task:core}
          Интегрировать вычислительное ядро pysatl-core в библиотеку pysatl-mpest.
    \item\label{task:refactoring}
          Выполнить рефакторинг модулей оценщиков, оптимизаторов и инициализаторов библиотеки для дальнейшего развития.
    \item\label{task:structure-selection}
          Разработать модуль выбора структуры смеси.
    \item\label{task:functionality-implementation}
          Реализовать функциональность, необходимую для воспроизведения экспериментов из выбранных статей.
    \item\label{task:release}
          Подготовить документацию и опубликовать библиотеку.
    \item\label{task:approbation}
          Провести апробацию библиотеки.
\end{enumerate}
