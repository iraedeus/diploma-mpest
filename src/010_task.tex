\section{Постановка задачи}
\label{sec:task}

Целью работы является развитие библиотеки pysatl-mpest для оценки параметров и выбора структуры конечных смесей одномерных непрерывных распределений, а также публикация её релиза.

Для достижения этой цели необходимо решить следующие задачи:

\begin{enumerate}
    \item Спроектировать архитектуру библиотеки.
    \item Интегрировать вычислительное ядро pysatl-core.
    \item Выполнить рефакторинг существующей реализации.
    \item Реализовать методы инициализации параметров смеси.
    \item Реализовать методы выбора структуры смеси.
    \item Провести экспериментальное исследование.
    \item Опубликовать библиотеку.
    \item Провести апробацию результатов работы.
\end{enumerate}
